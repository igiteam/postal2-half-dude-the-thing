//  Sounds located in this file are typically being used as loop sounds where we 
//  need 1 or 2 things that we don't get with 'loopsound':
//     1. to guarantee that when we start the sound it starts at the beginning of the asset
//	   2. to guarantee that we don't respatialize certain loop sounds that are playing in the level
// 
// WARNING!! (5/04) Please note that the term milliseconds is wrong here, 
//    1 second is a value of 100000
// 	  e.g. loopend 500000  seems to mean loop at the end of 5 secs
//
//
// Possible Keys:
// --------------
// sound <filename> (The start of every definition)
// mindist <defaultmindist> (specifies the default minimum distance at which this sound is played
// maxdist <defaultmaxdist> (does not work)
// volume <defaultvolume> (specifies the default volume)
// pitch <defaultpitch> (specifies the default pitch)
// loopstart <startofloop> (specifies the time in ms which is the start of the loop)
// loopend <endofloop> (specifies the time in ms which is the end of the loop), -1 means EOF
// maxnumber <int> 
// maxfactor <int>
// localsound (specifies this sound as a local sound
// defaultmindist <int> (specifies the default minimum distance for all sounds)
// defaultmaxdist <int> (does nothing)
// defaultvolume <float> (specifies the default volume for all sounds) 
//
// Sample Formatting:
// ------------------
// sound "blah"
// 	localsound
// 	volume 1
//	mindist 1000
//
//
//	!USE TABS!
//
// **********************************************************************************
// **********************************************************************************
// **********************************************************************************
//
// YOU MUST:
// dwc: EXAMPLE OF USING 3 SOUNDS FOR A RISING, LOOPING, DECAYING BLEND
// Make sure your sound in ubersound is playing on CHAN_WEAPON.
// Make sure that in ubersound, your file is set to 'loaded', not 'streamed'
